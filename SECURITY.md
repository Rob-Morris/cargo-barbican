# Security Policy

cargo-barbican is a supply-chain security tool, so vulnerability reports are
taken seriously. Please help by reporting suspected vulnerabilities privately.

## Reporting a Vulnerability

Please do **not** open a public issue for a suspected vulnerability.

Report privately via either channel:

- Email: [r@underware.gg](mailto:r@underware.gg)
- GitHub private vulnerability reporting (the **Report a vulnerability**
  button under the repository's Security tab).

Include what you can: affected version or commit, reproduction steps, and your
assessment of impact. Partial reports are still welcome.

## What to Expect

This project is maintained by a single person, so please set expectations
accordingly:

- Acknowledgement of your report within 7 days.
- An initial assessment (confirmed, needs more information, or not a
  vulnerability) within 14 days.
- Confirmed vulnerabilities are fixed as a priority, but there is no
  guaranteed fix timeline. You will be kept informed of progress.
- Please allow a fix to be released before any public disclosure, and
  coordinate disclosure timing with the maintainer.

Credit is given to reporters in release notes unless you prefer otherwise.

## Supported Versions

Only the latest release line receives security fixes. Older releases are not
patched — upgrade to the latest release to receive fixes.
