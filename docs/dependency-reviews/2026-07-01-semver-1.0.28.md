## Rationale

`cargo barbican pick` must evaluate user-supplied Cargo-style version
requirements before recommending an exact crate version. Range correctness is a
supply-chain decision: choosing the wrong version can admit the wrong artefact
or make the tool disagree with Cargo's resolver. Rather than hand-roll caret,
tilde, comparator-set, pre-release, and build-metadata semantics,
cargo-barbican uses the proven `semver` crate.

The crate is Rust-team-ecosystem infrastructure, maintained by David Tolnay,
and is used broadly in Rust tooling, including Cargo-adjacent workflows.
