## Advisory Review

- Sources checked:
  - local RustSec advisory DB clone
  - `cargo audit`
  - `cargo deny check advisories bans sources`
- Findings:
  - local RustSec matches exist for `time`, but the chosen version is acceptable:
    - `RUSTSEC-2020-0071` affects `time < 0.2.23` for local-offset functions on Unix-like systems; `0.3.47` is outside the affected range

  - `cargo audit` completed successfully against the final pinned lockfile
