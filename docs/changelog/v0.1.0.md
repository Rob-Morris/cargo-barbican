# v0.1.0 — 2026-05-24

**Summary** Establish cargo-barbican scaffolding, policy, and hook workflow

Initial repo version and first structured changelog entry. This baseline
bundles the workspace scaffold with the first contributor-policy and workflow
surfaces.

- `Cargo.toml`, `crates/barbican/Cargo.toml`, and `crates/cargo-barbican/Cargo.toml` establish the two-crate workspace at `0.1.0`.
- `docs/` adopts the layered documentation structure, including user, functional, architecture, contributor, standards, and dependency-review surfaces.
- `README.md`, `docs/CHANGELOG.md`, `docs/standards/changelog.md`, and `docs/standards/commit-messages.md` establish the project introduction plus the initial changelog and commit-message standards.
- `.canaries/pre-commit.md`, `docs/standards/canary.md`, `docs/contributor/process.md`, `tools/git-hooks/pre-commit`, and `tools/git-hooks/commit-msg` establish the distributed local hook and canary workflow, with versioned amend exceptions kept off `main`.
