# v0.17.0 — 2026-07-01

**Summary** Add pick command for semver version discovery

## Features

- Adds `cargo barbican pick [--min-age-days N] <crate|crate@range>` for
  read-only crates.io version discovery. `pick` evaluates Cargo-compatible
  semver ranges, excludes yanked versions, pre-releases, and too-fresh
  candidates, then prints the selected exact `crate@version`.
- Adds the reviewed `semver = "=1.0.28"` dependency to the pure library for
  Cargo-compatible version requirement evaluation.

## Safety

- `pick` uses the same release-age policy and reviewed release-age exception
  seam as `age`, `inspect`, `resolve`, `update`, and `assess`.
- `pick` is read-only. It fetches crates.io version metadata and does not edit
  manifests or `Cargo.lock`.
- The `semver` dependency was reviewed before it entered the graph. The review
  record is `docs/dependency-reviews/2026-07-01-semver-1.0.28.md`.

## Notes

- The exact-spec parser remains hand-rolled and exact-only. Full semver range
  semantics are scoped to `pick`.
