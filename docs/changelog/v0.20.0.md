# v0.20.0 — 2026-07-07

**Summary** Add JSON audit output and surface advisory remediation facts

## Features

- Adds `cargo barbican audit --format text|json`. The default text report is
  unchanged for passing runs; `--format json` emits a stable, `schema_version`ed
  report of advisory findings, dispositions, scanner completeness failures, and
  native delegated ignores for CI and tooling consumers.
- Enriches advisory findings with the scanner-provided title, risk label, and
  patched-version ranges, and — when frozen Cargo metadata is available — the
  shortest workspace-root dependency path to each affected package, so a failing
  audit shows both what is wrong and how to remediate it.

## Safety

- Surfaces dependency-path enrichment failures explicitly (a
  `dependency_paths_available` flag in JSON, a one-line stderr note in text)
  instead of silently rendering a missing path, and keeps the pass/fail verdict
  driven solely by advisory disposition rather than by best-effort metadata
  enrichment.

## Refactoring

- Routes cargo-deny and cargo-audit findings through one keyed de-duplication
  and detail-merge path so remediation metadata is retained when both scanners
  report the same advisory.
