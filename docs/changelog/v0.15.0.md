# v0.15.0 — 2026-07-01

**Summary** Add version flag and exact spec equals tolerance

## Features

- `cargo barbican --version` and `cargo-barbican --version` now print the
  shipped cargo-barbican version.
- CLI candidate specs now accept one optional leading `=` before the version:
  `crate@=1.2.3` is normalised to `crate@1.2.3`.

## Notes

- Manifest exact-version requirements are unchanged. They still require a
  leading `=`, because bare Cargo manifest requirements such as `1.2.3` are
  ranges rather than exact pins.
- Version ranges such as `crate@^1`, `crate@>=1`, `crate@=^1`, and wildcard
  specs remain invalid CLI candidate specs.
