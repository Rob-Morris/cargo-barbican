# v0.19.0 — 2026-07-06

**Summary** Harden reviewed-target gates and CLI output contracts

## Safety

- Hardens reviewed-target enforcement so matching `Cargo.lock` entries must be
  crates.io sourced and checksum observations must not be satisfied by a
  checksumless or non-crates.io doppelganger.
- Detects manifest `[patch]` and repo `.cargo/config.toml` source replacement
  surfaces that can change the artefact behind a reviewed target.
- Restores lockfiles through a guard-backed path for failed `resolve` and
  `update` operations, and writes reviewed-target policy updates atomically.
- Centralises CLI failure rendering and escaping so policy reports and
  infrastructure errors use the documented stream and terminal-safety contract.

## Features

- Adds CI adoption guidance that treats the gate as `audit` plus `verify`,
  while keeping `verify` deterministic and repo-local.
- Improves command help text and output-contract documentation for shell and CI
  consumers.

## Refactoring

- Reworks assessment findings, reviewed allowance handling, release-age gate
  classification, pin-add planning, and command-module structure so future
  policy surfaces share one rule owner.
- Splits the CLI integration tests into per-command modules with shared
  fixtures and adds hostile-input, flag-coverage, branch-guard, and HTTP-stub
  regression tests.
