# v0.5.0 — 2026-06-07

**Summary** Add explicit baselines and dry-run review previews

- Adds explicit non-git baselines for `age-lock --base-lockfile`,
  `assess --base-dir`, and `review --base-dir`, while keeping git `HEAD` as
  the default baseline.
- Adds `resolve --dry-run` to preview the would-be `Cargo.lock` update diff
  without mutating the real workspace.
- Adds `--min-age-days` to `resolve` so an operator can make an invocation-
  scoped release-age exception while both resolve-time checks still run.
- Uses `similar` for local unified-diff rendering and records the dependency
  review for that new surface.
- Injects a single CLI clock into age-sensitive command paths so release-age
  tests and command behaviour are stable across time.
