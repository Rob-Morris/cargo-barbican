# v0.24.0 — 2026-07-22

**Summary** Ship the insiders release gate and deployment baseline

## Features

- Adds `cargo barbican gatehouse pre-release`, the blessed fail-fast release
  workflow: blocking direct-dependency inventory floor, blocking
  advisory/source audit, then the blocking reviewed-target and locked
  build/test verification gate.
- Adds the direct-dependency `inventory --enforce` coverage floor and makes its
  report distinguish blocking direct coverage from observational transitive
  backlog and undeclared execution surfaces, enforced incomplete review
  records, and other observational manifest/source findings.
- Makes `policy init --ci github` emit the standard Gatehouse workflow with an
  immutable cargo-barbican tag, exact reviewed cargo-deny/cargo-audit versions,
  and full-SHA action pins.
- Expands the adoption package with generated CI, a client-side pre-commit
  template, and user guides for initial adoption, CI, hardening, configuration,
  and day-two dependency operations.

## Hardening

- Anchors command execution to Cargo's discovered workspace root and strengthens
  fail-closed handling for malformed manifests, policy-file path types,
  workspace discovery, delegated-tool availability, and terminal diagnostics.
- Makes direct-dependency enforcement Cargo-metadata- and lockfile-edge-aware,
  including renamed, optional, development, build, target-specific, external,
  and same-name multi-version dependency cases.
- Keeps offline inventory honest when graph collection fails by labelling
  crates.io and non-crates.io source gaps unclassified instead of guessing
  whether they are enforced direct dependencies or observational backlog.
- Keeps crates.io metadata and tarball requests on HTTPS throughout redirect
  chains, while preserving the validated loopback HTTP seam for local tests.
- Preserves the distinct semantics of `audit` and `verify`: advisory state can
  change with world time, while reviewed-target/build/test verification remains
  repo-local and deterministic.

## Distribution

- Defines the initial release as an insiders build installed from immutable git
  tag `v0.25.0`; crates.io publication remains deferred.
- Exercises the test suite and dogfooded release gate on both Ubuntu and macOS,
  the two supported platform families. Windows remains experimental.
- Documents the current trust boundary honestly: exact direct-dependency
  coverage is enforced, while routine transitive coverage and undeclared
  execution surfaces remain visible review backlog.
