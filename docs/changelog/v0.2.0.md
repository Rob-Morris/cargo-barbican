# v0.2.0 — 2026-06-07

**Summary** Add routine Rust dependency update gates

- Adds the routine update commands `cargo barbican age`, `age-lock`,
  `resolve`, `assess`, `review`, `audit`, and `verify`.
- Introduces the pure Rust policy core for release-age checks, manifest
  dependency parsing, lockfile comparison, Cargo metadata inspection, and
  assessment classification.
- Adds the binary subprocess boundary for `cargo`, `git`, `cargo audit`, and
  `cargo deny`, with integration coverage for routine dependency workflows.
- Documents the current CLI surface and contributor process for local
  dependency-policy use.
