**Summary** Bootstrap cargo-barbican's reviewed dependency baseline

This version lands the dependency precursor bundle that unblocks real
implementation work while keeping the repo inside its own review discipline.

- `deny.toml` adds the initial delegated `cargo-deny` policy baseline for advisories, bans, and allowed sources.
- `docs/dependency-reviews/2026-05-25-cargo-audit-0.22.1.md`, `docs/dependency-reviews/2026-05-25-cargo-deny-bootstrap.md`, `docs/dependency-reviews/2026-05-25-rust-bootstrap-inherited-core-set.md`, `docs/dependency-reviews/2026-05-25-ureq-3.3.0.md`, and `docs/dependency-reviews/2026-05-26-time-0.3.47.md` capture the direct dependency, tool, and policy trust decisions behind the bundle.
