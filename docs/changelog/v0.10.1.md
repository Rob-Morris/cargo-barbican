# v0.10.1 — 2026-06-21

**Summary** Harden execution-surface collision detection

## Fixes

- Hardens `package_surfaces` so the `assess` classifier unions execution
  surfaces across all cargo metadata packages with the same crate name and
  version instead of using the first match.
- Preserves the existing zero-match `PackageVersionNotFound` error and the
  common single-match behaviour.

## Safety

- Closes the deferred enforcement-path source-collision fail-open where a
  git, path, or alternate-registry package could shadow a same-name/same-version
  package and hide its `build.rs`, proc-macro, or native `links` surface from
  policy assessment.
- Keeps the inventory graph path unchanged; it already unions source-distinct
  surfaces for reporting.

## Documentation

- Removes the now-closed enforcement source-collision item from the deferred
  non-sequenced design work in `docs/architecture/overview.md`.
