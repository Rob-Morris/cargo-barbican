# v0.44.0 — 2026-11-18

**Summary** Show bounded Cargo tool review and install progress

- Add best-effort stderr phases and genuine source-inspection counts to CLI
  `tool review` and `tool install`, with periodic elapsed updates on terminals
  and bounded phase-only redirected output. JSON stdout remains unchanged.
- Keep diagnostic writes off the operation path with bounded state and an
  independent writer. Child cancellation, source checks, installation authority
  and publication proceed independently of progress output.
- Preserve captured native Cargo artifact output, independent policy verdicts
  and mandatory installation disclosures. Progress never certifies safety or
  successful installation; existing injected writer APIs remain compatible.
- Remove the private verifier fork's unused certificate presentation layer and
  its Chrono dependency after RUSTSEC-2026-0543 marked Chrono unmaintained.
  Verification behaviour stays unchanged; no advisory exception is added.
