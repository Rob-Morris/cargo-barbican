# v0.16.0 — 2026-07-01

**Summary** Rename resolve to update and reclaim resolve

## Features

- Renames the exact-version re-pin command from `cargo barbican resolve` to
  `cargo barbican update`. The command behaviour is unchanged: it still
  release-age checks requested exact versions, runs `cargo update --precise`,
  rechecks newly selected transitive crates, and supports `--dry-run`.
- Reclaims `cargo barbican resolve` for whole-graph lockfile resolution. It now
  runs `cargo generate-lockfile` for the current manifests, checks newly
  selected crates.io versions against release-age policy, and restores the
  original `Cargo.lock` if the age gate fails.

## Notes

- This implements the approved subcommand vocabulary from
  `Cargo-Barbican CLI Command Vocabulary Design — Resolution, Lockfile Generation, And Updates`.
- Historical changelogs and dependency review records keep their as-run command
  text.
