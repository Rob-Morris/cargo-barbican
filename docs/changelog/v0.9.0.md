# v0.9.0 — 2026-06-21

**Summary** Add dependency inventory audit

## Features

- Adds `cargo barbican inventory`, a read-only whole-repo dependency inventory
  and reviewed-policy coverage audit.
- Reports direct manifest requirements, resolved crates.io packages,
  non-crates.io sources, reviewed-target coverage, declared execution-surface
  allowances, observational findings, and policy coverage gaps.
- Resolves workspace-inherited direct dependencies against root
  `[workspace.dependencies]` so inherited requirements are labelled correctly
  instead of being treated as loose member-local pins.

## Safety

- Keeps Slice 1 offline and read-only: the command reads `Cargo.lock`,
  workspace manifests, optional `reviewed-targets.toml`, and checked-in review
  record facts, then exits successfully even when it reports inventory gaps.
- Escapes C0 control characters in untrusted rendered fields so crafted
  lockfile, manifest, or policy strings cannot forge or erase terminal output.
- Distinguishes observational findings from policy coverage gaps so an absent
  policy file does not imply that unresolved coverage has been enforced.

## Documentation

- Updates user command docs, functional CLI docs, and contributor
  specification notes to describe the offline inventory scope, approximate
  workspace-member discovery, source-replacement boundary, and checksum
  enforcement boundary.
- Records deferred cross-command symlink hardening for workspace-member and
  review-record discovery as non-sequenced design work.
