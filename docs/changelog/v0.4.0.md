# v0.4.0 — 2026-06-07

**Summary** Add reviewed-target enforcement and verification

- Adds `reviewed-targets.toml` parsing for named dependency families,
  checked-in review records, exact direct requirements, and exact resolved
  crate selections.
- Adds `cargo barbican pin-check` to enforce reviewed direct and resolved
  targets, including optional crates.io `checksum_sha256` reconciliation
  against `Cargo.lock`.
- Wires `cargo barbican verify` through the reviewed-target gate before locked
  build and test verification.
- Adds templates and contributor documentation for reviewed targets, review
  records, and local verification workflows.
