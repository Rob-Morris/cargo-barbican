# v0.14.2 — 2026-07-01

**Summary** Polish pre-release adoption guidance

## Fixes

- `cargo barbican policy init` now points first-run adopters at the upstream
  adoption guide URL instead of a repo-local `docs/user/adoption.md` path that
  does not exist in consumer repositories.

## Documentation

- The README now uses a pre-release `--branch main` git install command rather
  than advertising a `v*` tag that has not been cut yet, and carries an explicit
  reminder to restore the `--tag` install command before the first public
  release.
- Tool-review guidance now states that `gatehouse candidate` builds a
  synthetic single-dependency library graph for tool crates. It is partial
  pre-install evidence, not proof of `cargo install --locked` semantics or the
  tool's real install graph.
