# v0.18.0 — 2026-07-06

**Summary** Add pin add and harden verify gating

## Features

- Adds `cargo barbican pin add` as an offline reviewed-family scaffolder. It
  composes a `reviewed-targets.toml` family entry and a dependency-review
  record stub from existing `Cargo.lock` facts.
- Extends `verify` so it always runs the reviewed-target gate before locked
  build/test verification and fails closed when no active reviewed families
  are configured.
- Adds the DD-003 pin command namespace decision record and updates adoption,
  command, functional, and contributor docs for the new pin workflow.

## Safety

- `pin add` refuses ambiguous versions, existing family coverage, missing
  lockfile targets, symlinked policy paths, and review-record path conflicts.
- Review-record scaffold writes and `reviewed-targets.toml` updates share the
  same fail-closed filesystem scaffold protections used by policy init.
- `verify` now makes the reviewed-target precondition explicit before any
  build or test execution can load unreviewed build scripts or proc macros.

## Notes

- This release introduces the user-facing pin scaffolding workflow that later
  hardening releases build on.
