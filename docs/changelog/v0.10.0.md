# v0.10.0 — 2026-06-21

**Summary** Add live execution-surface inventory

## Features

- Extends `cargo barbican inventory` with live graph execution-surface
  reporting collected through `cargo metadata --format-version 1 --frozen`.
- Reports `build.rs`, proc-macro, and native `links` surfaces from the resolved
  dependency graph and cross-references them against reviewed
  `allowed_surfaces`.
- Distinguishes declared live surfaces from undeclared ones, classifying
  undeclared surfaces as policy coverage gaps when `reviewed-targets.toml` is
  configured and as observational findings before policy adoption.

## Safety

- Keeps `inventory` read-only: frozen metadata collection cannot update
  `Cargo.lock`, and collection failures still render the offline manifest,
  lockfile, and reviewed-target sections.
- Excludes first-party workspace members from live dependency-surface findings
  using cargo metadata package IDs, while preserving git, path, and
  alternate-registry dependency surfaces.
- Unions surfaces across source-distinct packages with the same name and
  version so source collisions over-report rather than hide execution surfaces.

## Documentation

- Updates user command docs, functional CLI docs, and contributor
  specification notes to describe live-surface collection, declared-vs-undeclared
  rendering, and the not-collected failure mode.
- Records the pre-existing `package_surfaces` enforcement-path source-collision
  follow-up as deferred non-sequenced design work.
