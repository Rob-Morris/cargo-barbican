# v0.3.0 — 2026-06-07

**Summary** Add crates.io inspection for pre-add review

- Adds `cargo barbican inspect` for exact crates.io candidates before they are
  added to a workspace.
- Downloads and validates crate tarballs, compares the local SHA-256 digest to
  crates.io metadata, and reports yanked, age, build-script, proc-macro,
  native-source, and IOC signals.
- Adds reviewed dependency records for the tarball and digest inspection stack
  introduced by this slice.
- Shapes `assess` findings into structured categories so inspection and update
  assessment report the same policy vocabulary.
