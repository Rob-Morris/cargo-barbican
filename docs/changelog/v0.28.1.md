# v0.28.1 — 2026-09-16

**Summary** Harden public distribution and remediate rustls

## Security

- Updates the transitive TLS packages to `rustls 0.23.45` and
  `rustls-webpki 0.103.15`, removing `RUSTSEC-2026-0285` from the shipped
  dependency graph without an advisory exception.
- Adds the exact artefact checksums and reviewed `rustls` build-script surface
  to `reviewed-targets.toml`. The temporary release-age exception applies only
  to `rustls 0.23.45` and becomes inert after the normal seven-day quarantine.
- Records the inherited and cargo-barbican-specific evidence in
  `docs/dependency-reviews/2026-09-15-rustls-advisory-remediation.md`.
- Activates GitHub private vulnerability reporting, secret scanning and push
  protection for the now-public repository. `SECURITY.md` keeps
  `r@underware.gg` as the private email channel.

## Distribution

- Removes the private-repository Cargo credential workaround from the README
  and user/contributor guidance. Public tagged installs now use Cargo's normal
  anonymous Git fetch path.
- Keeps the documented early-insiders scope while advancing every generated
  workflow, template sync header and install example to the immutable
  `v0.28.1` tag.
- Removes tracked build-cache artefacts from the already ignored
  `docs/.cargo-target/` directory.
